## 📌 Overview

ACE (Applicant Capability Evaluation) is an AI-powered Talent Intelligence Platform designed to help recruiters evaluate candidates beyond traditional resume screening.

Unlike conventional Applicant Tracking Systems (ATS), which primarily rely on keyword matching, ACE performs intelligent candidate evaluation by analyzing resumes, GitHub profiles, portfolios, technical skills, education, and experience to identify the most suitable candidates.

The platform enables recruiters to reduce manual screening time, improve hiring quality, and make data-driven recruitment decisions.

---

# ❗ Problem Statement

Traditional Applicant Tracking Systems (ATS) rely heavily on keyword-based resume parsing.

This creates several challenges:

- Candidates without real skills can manipulate resumes using keywords and get shortlisted.
- Skilled candidates may be rejected because their resumes lack specific keywords.
- Recruiters spend significant time manually validating shortlisted candidates.
- Companies waste valuable resources interviewing candidates who do not possess the required capabilities.
- The overall hiring process becomes slower, more expensive, and less efficient.

---

# 💡 Solution

ACE solves this problem by evaluating candidates beyond their resumes.

The platform analyzes multiple aspects of a candidate including:

- 📄 Resume Analysis
- 💻 GitHub Repository Evaluation
- 🌐 Portfolio Assessment
- 🛠 Technical Skills
- 🎓 Education
- 💼 Experience
- 🤖 AI Candidate Evaluation
- 📊 Overall Candidate Ranking
- ❓ AI-Generated Interview Questions

This provides recruiters with a more comprehensive understanding of each applicant's capabilities before making hiring decisions.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/chandrakala0223/ACE-Applicant-Capability-Evaluator-.git
```

## Install Dependencies

```bash
pnpm install
```

## Run Frontend

```bash
pnpm dev
```

## Run Backend

```bash
pnpm start
```
